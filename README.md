# BiomeBGC_borealPredictions

## What this is

This repository runs **Biome-BGC** — a model that simulates forest growth and carbon/water
cycling — across the Canadian boreal forest, to predict how forest productivity might change
under different future climate scenarios. It ties together two other modules that do the
underlying work, and adds the scripts needed to set up the experiment, run it, and turn the
results into maps and figures.

## How it fits into the BiomeBGC toolkit

This project runs Biome-BGC itself throught two modules:

- **`BiomeBGC_dataPrep`** — prepares and spatializes the climate data and plant/ecosystem
  parameters that Biome-BGC needs as input.
- **`BiomeBGC_core`** — runs the actual Biome-BGC model for a given area and set of inputs.

This repository's job is to decide *what* to run (which regions, which climate scenarios) and
*how* to run it (in parallel, across many combinations), and then to summarize and visualize the
results.

## Repository structure

| Path | Contents |
|---|---|
| `global.R` | Sets up a single SpaDES simulation run: defines the study area, the spatial grid resolution, which CO2 scenario and climate model to use, and which model outputs to save. |
| `expt.R` | The main experiment driver. Loops over all combinations of ecoprovince, CO2 scenario, and climate model, and launches the simulations in parallel. |
| `scripts/` | Standalone R scripts for processing inputs and analyzing/visualizing outputs — e.g. preparing climate indices, mapping predicted productivity (NPP), and validating model results against real-world flux tower measurements. |
| `data/processed/` | Processed data products used in or produced by the analysis (e.g. climate indices, NPP rasters). |
| `inputs/` | Large spatial input layers (forest boundaries, tree species maps, hydrology). Not tracked in git — must be obtained separately. |
| `figures/` | Plots generated by the analysis scripts (study area map, climate summaries, validation results, productivity maps). |
| `cache/` | SpaDES simulation cache, used to avoid re-running unchanged steps. Not tracked in git. |

## Experiment design

The main experiment (`expt.R`) runs Biome-BGC separately for each combination of:

- **boreal ecoprovinces** (broad ecological regions of the boreal forest)
- **2 CO2 emissions scenarios** (RCP 4.5 and RCP 8.5)
- **3 climate models** (RCM4, GCM4, Hadley)

Runs are parallelized across many processor cores to keep total runtime manageable.

## Running this project

1. `global.R` sets up and can run a single scenario — useful for testing.
2. `expt.R` runs the full set of scenario combinations and is intended for the full
   experiment; it expects substantial compute resources (parallel cores) and disk space for
   outputs.
4. Once outputs are produced, the numbered scripts in `scripts/` can be run to process results
   and generate the figures used for validation and reporting.
